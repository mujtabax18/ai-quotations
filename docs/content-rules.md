# Content Rules

1. Prefer original wording.
2. AI-generated text must use `"source": "ai"`.
3. Do not invent attribution to a real person.
4. Use `author: ""` for original AI-generated content.
5. Avoid copying famous quotations verbatim unless redistribution rights are clear.
6. Avoid duplicates and near-duplicates.
7. Reuse an existing category where possible.
8. Preserve UTF-8 text exactly.
9. Keep repository content separate from local user state.
