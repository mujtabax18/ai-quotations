# Category Taxonomy

The supplied export contains 39 category labels.

Largest categories:

- Anger Management — 36
- Personal Growth — 34
- Self-Discipline — 34
- Wisdom — 34

There are overlapping labels such as:

- Growth / Personal Growth
- Self-control / Control / Discipline / Self-Discipline
- Self-mastery / Emotional mastery

This starter repository preserves the original labels for compatibility.

For future AI content, prefer existing categories. If categories are consolidated
later, add an alias/migration layer rather than silently changing already-downloaded
records.
